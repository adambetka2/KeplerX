# Results kept in git

Lean, verifiable records of the completed 406,547-source survey, bounded
development experiments and the M/K programme's target lists. Full survey
evidence stays on the server (`/srv/kbonus/survey`) and in the Mac export
(`/Volumes/discPCIe/kbonus`); see `../docs/survey-results.md`.

- `kbonus-20261010/`: final BOI catalogues as gzip with original SHA-256 values
  in `lean-backup-index.json`, the compact outcome ledger of all 99,505
  proposals, frozen policies, bindings, verification receipts and the survey's
  completion record `summary.json`.
- `boi-release-20261005.json`: the first BOI release list.
- `boi-validation/`: the 125-entry delivery selection, the manual selection,
  the catalogue flags and the validation record described in
  `../docs/boi-validation.md`.
- `experiments/`: development-pilot measurements and links to preserved local
  evidence; these are not survey outcomes or discovery claims.
- `mk-survey-targets-20261014.csv` and `.json`: the M/K survey's 57,889 target
  rows with the hopeless flag (6,239 skipped, 51,650 queued), and the census,
  noise and criterion record; see `../docs/mk-survey.md`.

A BOI is a pipeline disposition. Nothing here is a validated planet.
